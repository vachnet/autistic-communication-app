Thai picture-based communication app preview.

- Subject, verb, object, and modifier selection.
- First tap previews audio; the next tap on the same card confirms.
- Compatible vocabulary choices and per-device frequency ordering.
- Finish after the subject and verb, or add more detail.
- Replay a sentence or start again.
- Add personal cards using a photo and a voice recording without typing.
- Choose green, warm cream, or blue-gray colors and turn automatic sentence speech on or off.
- Scrolling layouts adapt columns to available width and system text size.

Download `communicate-together-android.apk` on an Android device, open it, and allow installation from the browser or file manager when Android asks.

This is a testing build signed with the Expo template debug key. Device testing and caregiver feedback are required before everyday use. Built-in words use device Thai text-to-speech; install a Thai voice to use them offline. Custom cards use your recordings. Starter illustrations use emoji and may look different across devices.

Personal photos and recordings stay in local app storage; uninstalling deletes its data.
